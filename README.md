# Geni — AI-Powered Knowledge Assistant

Geni is a full-stack AI-powered conversational assistant that allows users to interact with an AI, maintain persistent conversations, and securely manage their chat history.

The application combines a React frontend with a Node.js/Express backend, MongoDB for persistent data storage, JWT-based authentication, and the Google Gemini API for AI-generated responses.

## ✨ Features

- 🤖 AI-powered conversations using Google Gemini API
- 🔐 User authentication with JWT
- 🔒 Protected backend API routes
- 👤 User-specific chat history
- 💬 Create and manage multiple conversations
- 🗑️ Delete conversation threads
- 💾 Persistent chat storage with MongoDB
- 📱 Responsive design for desktop and mobile
- 📂 Slide-out sidebar for mobile devices
- 📝 Markdown rendering for AI responses
- 💻 Syntax highlighting for code blocks
- 🚪 Secure logout functionality
